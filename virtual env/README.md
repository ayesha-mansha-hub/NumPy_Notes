# NumPy Fundamentals

Hands-on practice notebooks covering NumPy essentials, built as part of my self-directed path toward becoming an AI/ML Engineer.

## What's covered (Phase 1)

- Creating arrays with `np.array()`
- Difference between `python list` and `Numoy Arrays`
- Inspecting arrays: `shape`, `ndim`, `size`, `dtype`, `itemsize` , `nbytes`
- Reshaping arrays with `reshape()`
- Flattening arrays with `flatten()` vs `ravel()` (and the difference between them)
- Transposing matrices with `.T`

## Why this matters

NumPy arrays (tensors) are the foundation of almost every ML/DL computation — understanding how to inspect and reshape them is a prerequisite before moving into linear algebra, deep learning frameworks, and model building.
